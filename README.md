# صادرات به عراق

کسب‌وکار صادرات کالاهای ایرانی به کشور عراق.

## اصول کاری

- فقط کالاهای **مجاز** برای خروج از ایران
- امور گمرکی و ترخیص بر عهده‌ی ترخیص‌کار است

## ساختار ریپازیتوری

- `rules/` — قوانین و مجوزهای صادرات از ایران
- `market-iraq/` — تحقیق بازار عراق: تقاضا، قیمت‌ها، رقبا
- Issues — کارهای قدم‌به‌قدم پروژه
