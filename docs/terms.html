What this tool is

asal is a small tool used by one export business to manage its own TikTok presence. It helps publish the business's own product videos to TikTok and display the account's basic profile and public videos.

Permission

This tool accesses a TikTok account only after the account owner gives permission through TikTok's own login and approval screens. No permission means no access.

Acceptable use

The tool may only be used for the business's own TikTok account and its own product content. The user is responsible for the videos and text they publish through the tool and for following TikTok's rules and applicable laws.

Disconnecting

The account owner can disconnect this tool at any time from inside TikTok's settings, which ends the tool's access.

No sale of data

We do not sell TikTok account data to anyone.

Availability

This is a small internal tool. It is provided as-is, without promises that it will always be available or error-free.
