# قوانین صادرات از ایران

نکات مهم درباره‌ی کالاهای مجاز و مجوزهای صادراتی.

## اصل کلی

- فقط کالاهایی که خروج آن‌ها از ایران **قانونی و مجاز** است.
- استعلام به‌روز بودن مجوزها قبل از هر محموله.

## مدارک

- امور گمرکی و ترخیص بر عهده‌ی **ترخیص‌کار** است.
- مدارک هویتی و تجاری شرکت باید آماده و معتبر باشد.

> این فایل راهنماست؛ جزئیات هر کالا در ایشوهای مربوطه پیگیری می‌شود.
